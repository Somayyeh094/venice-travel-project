A responsive landing page showcasing Venice, built with pure **HTML and CSS**. Perfect for practicing semantic markup, Flexbox/Grid, and animations.

## Features ✨  
- **Semantic HTML5**: Clean, accessible structure.  
- **CSS Animations**: Smooth hover effects and transitions.  
- **Responsive Design**: Adapts to mobile/tablet/desktop.  
- **No Frameworks**: Pure vanilla code.  

## Tech Stack 🛠️  
- **Frontend**: HTML5, CSS3 (Flexbox/Grid)  
- **Deployment**: Netlify
